
# RoadGuard-OOD — Instructions Codex

## Projet
Projet universitaire Deep Learning Avancé + MLOps.
Délai : 3 semaines maximum.
Environnement : Windows, VS Code, PowerShell.
Équipe : Hadir et Nour.

## Stack cible
Python, PyTorch, YOLO11n, DVC, MLflow,
ONNX Runtime, FastAPI, React, Docker Compose,
GitHub Actions.

## Règles
- Examiner le code existant avant toute modification.
- Préserver les fichiers et configurations fonctionnels.
- Favoriser des solutions simples, testables et maintenables.
- Ne jamais inventer de résultats expérimentaux.
- Ne jamais modifier les données brutes.
- Ne jamais mélanger les données train, validation et test.
- Ne jamais utiliser les résultats OOD pour sélectionner un modèle.
- Ne jamais committer les datasets, poids ou secrets dans Git.
- Exécuter les tests après chaque modification.
- Signaler clairement les erreurs et limitations.
- Ne pas installer de dépendances lourdes sans nécessité.
- Ne pas exécuter git push sans accord.

## Collaboration
Une branche principale main et des branches courtes
pour les développements futurs.

## Réponse attendue après chaque tâche
- Fichiers créés ou modifiés.
- Tests réellement exécutés.
- Résultats et erreurs.
- Commandes PowerShell de vérification.
- Prochaine action proposée.

Ne pas commencer automatiquement la tâche suivante.
